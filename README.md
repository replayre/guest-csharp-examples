# replay.re BlackICE Cyberpunk 2077 Multiplayer Example Bundles

This repo contains example bundle code for the [replay.re](https://replay.re) Cyberpunk2077 Multiplayer platform.


For more information on UGC bundles and how to create them see our docs at
[docs.replay.re](https://docs.replay.re/ugc/authoring/)

## [gamemodes](gamemodes/)

A complex FFA, racing and free roam game mode. Features a lobby and voting system,
supports delayed joining, score boards, chat and ban lists.

A good resource to start learning the scripting escosystem
